Documentation

How the census is built, and downloadable files that map each related DOI to its repository (not only the summary charts).

Method

  1. List UniCA HAL notices with relatedData_s, relatedPublication_s DOIs, or seeAlso_s.
  2. Record the HAL source field on every token (provenance for corrections).
  3. Optional modifiedDate_tdate window for incremental refresh; merge by halId_s.
  4. Parse each token as DOI, URL, HAL id, or other.
  5. Resolve new DOIs with DataCite REST API; reuse doi_resolutions.jsonl cache.
  6. Label repository and object_kind from landing host / publisher / known DOI prefix; never default unknown hosts to dataset_repo.
  7. Flag dataset_repo DOIs filed only outside relatedData_s (still listed there = supplementary, not a correction).
  8. Build dataset_to_publications (dataset_repo only) with sticky retrieved_at for the All repositories page.
  9. Write publication-level JSONL, DOI resolution JSONL, and CSV correspondence tables.

HAL query: (relatedData_s:*) OR (relatedPublication_s:10.*) OR (seeAlso_s:*) on https://api.archives-ouvertes.fr/search/UNIV-BOURGOGNE/. DOI API: https://api.datacite.org/dois/{doi}. Run: 2026-09-24T15:12:20Z → 2026-09-24T15:13:23Z.
