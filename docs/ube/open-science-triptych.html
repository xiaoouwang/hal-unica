Publication · data · software

Open science triptych

UBE candidates where a publication, research data, and software / source code are explicitly associated on HAL — the three pillars of open science, found from any corner of the triangle.

Why this combination matters

The open science triptych rests on opening three fundamental pillars: publications, research data, and free software or source code. Together they make results readable, reusable, and reproducible.

Publications

Make articles and books freely available to everyone in open access, without a paywall.

Research data

Structure, share, and disseminate the raw data behind the work according to the FAIR principles (Findable, Accessible, Interoperable, Reusable).

Software & source code

Open and document the codes and tools used to process the data, so that methods are transparent and results can be reproduced end to end.

The same triangle can be declared from three hubs on HAL. We merge them into one candidate per publication (DOI→HAL when needed):

  • Publication hub — scholarly notice with relatedData_s plus software (relatedSoftware_s / SWHID / code repo / linked SOFTWARE).
  • Software hub — SOFTWARE deposit with relatedPublication_s and relatedData_s.
  • Dataset hub — dataset-like notice (often OTHER) with relatedPublication_s and relatedSoftware_s; the notice itself is the data pillar.

Typing also uses TEI relatedItem COAR subtypes (dataset / software). We do not classify solely by DataCite DOI guessing.
