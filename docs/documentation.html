Documentation

How the census is built, and downloadable files that map each related DOI to its repository (not only the summary charts).

Method

  1. List UniCA HAL notices with relatedData_s via Search API cursor pagination.
  2. Parse each relatedData token as DOI, URL, HAL id, or other.
  3. Resolve every unique DOI with DataCite REST API.
  4. Label repository from landing host / publisher / known DOI prefix.
  5. Write publication-level JSONL, DOI resolution JSONL, and CSV correspondence tables.

HAL query: relatedData_s:* on https://api.archives-ouvertes.fr/search/UNIV-COTEDAZUR/. DOI API: https://api.datacite.org/dois/{doi}. Run: 2026-09-21T15:46:39Z → 2026-09-21T15:47:09Z.
